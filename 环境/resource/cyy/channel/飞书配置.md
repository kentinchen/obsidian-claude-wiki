## 飞书开放平台配置步骤

### 1. 创建自建应用
1. 登录 [飞书开放平台](https://open.feishu.cn/)。
2. 点击左侧「应用」 -> 「企业自建应用」。
3. 点击「创建自建应用」，填写应用名称（如 `hermes_office`）和描述，完成创建。

### 2. 启用机器人能力
1. 进入应用管理页面，点击左侧「添加应用能力」。
2. 找到「机器人」，点击「+ 添加」。
3. 确保应用状态为「**启用中**」或「**已发布**」（停用状态会导致 `activate_status: 2` 错误）。

### 3. 获取并配置凭证
1. 点击左侧「凭证与基础信息」。
2. 获取 `App ID` 和 `App Secret`。
3. 将这两个值填入 Hermes 本地环境变量文件 `$LOCALAPPDATA/hermes/.env` 中：
   ```env
   FEISHU_APP_ID=cli_aa5e83b19ef8dc07
   FEISHU_APP_SECRET=YTgzzBIY2WQYE4wRkTOwqd5KQRhpOXPB
   ```

### 4. 配置 API 权限
1. 点击左侧「权限管理」。
2. 在搜索框中搜索并开通以下权限：
   - `im:message:send` / `im:message:send_as_bot`（以机器人身份发送消息）
   - `im:message:receive`（接收消息，用于双向交互）
   - `im:chat:readonly`（可选，读取群信息）
   - `im:chat`（可选，群管理）
3. **注意**：如果权限变更，可能需要重新发布应用或刷新凭证。

### 5. 配置事件订阅（WebSocket 模式）
Hermes 默认使用 WebSocket 模式接收飞书事件，无需配置回调 URL：
1. 点击左侧「事件与回调」 -> 「事件配置」。
2. 点击「+ 添加事件」，搜索并添加：
   - `im.message.receive_v1`（接收消息）
3. 确保「请求地址设置」中的「接入方式」为 **WebSocket**。

### 6. 发布应用
1. 点击左侧「版本管理与发布」。
2. 点击「创建版本」 -> 「提交审核」。
3. 如果是企业内部应用且你是管理员，可以直接点击「强制发布」（或通过管理员审批）。
4. 发布后，应用状态会变为「已发布/已启用」。

### 7. 将机器人加入目标群组
**Hermes 必须向机器人所在的群发送消息**，否则会出现 `230002` 错误：
1. 在飞书桌面端或手机端，打开目标群组。
2. 点击右上角群设置（三个点）。
3. 找到「机器人」 -> 「添加机器人」。
4. 在弹出的列表中找到你的 `hermes_office` 机器人，点击添加。
5. 添加后，在群聊中 `@hermes_office` 测试是否响应。

### 8. 获取群 Chat ID
配置 Hermes 投递目标时需要群的 `chat_id`（格式 `oc_xxxx`）：
1. 在飞书群设置中，部分版本可直接查看。
2. 或者通过 API 获取：在 Hermes 机器人入群后，向群发送任意消息，查看 Gateway 日志或 Hermes 收到的第一条消息来源。
3. 获取后填入 `$LOCALAPPDATA/hermes/.env`：
   ```env
   FEISHU_HOME_CHANNEL=oc_d04bb3cbae2fcc7a83739726a41991b4
   ```

### 9. 重启 Hermes Gateway
修改飞书配置或凭证后，必须重启 Hermes Gateway 才能生效：
```bash
hermes gateway restart
```
可通过 `cat $LOCALAPPDATA/hermes/gateway_state.json` 检查 `feishu` 状态是否为 `connected`。

## 故障排查

### 常见错误码

| 错误码 | 含义 | 解决方案 |
|--------|------|----------|
| `10217` | App has been deleted | 应用已被删除，需重新创建 |
| `230002` | Bot/User can NOT be out of the chat | 机器人不在群中，需拉机器人进群 |
| `99991672` | Access denied / 权限不足 | 缺少所需 API 权限，需开通 |

### 诊断步骤
1. **检查 Gateway 状态** — 确保 `feishu` 状态为 `connected`
2. **验证凭证** — 用 curl 获取 tenant token 验证是否有效
3. **检查应用状态** — 确保飞书应用启用且权限完整
4. **确认机器人入群** — 向目标群发消息测试是否成功

```bash
# 修改后重启 Gateway

```
